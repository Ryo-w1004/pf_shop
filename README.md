# pf-shop
出品者が複数いる、フリマ型のショッピングサイト。

## 使用技術
- Laravel 13 / PHP 8.4
- MySQL
- Git / GitHub
- AWS

## 現在の状況
作成中。
- 完了: テーブル設計、会員登録、ログイン・ログアウト、退会、プロフィール編集(画像アップロードを含む)
- 作業中: パスワード変更

## 実装予定の機能
- 商品の出品・編集
- 商品一覧(検索・並び替え・ページング)
- 商品詳細・購入
- 取引相手との連絡掲示板
- お気に入り
- AWS での公開

## 制作で意識したこと
ユーザー目線で仕様を都度考える。

### AI との付き合い方
作業を全て AI に任せて書かせると、動いても自分で何も説明できないコードになったり、クライアント目線や保守の観点では実用的でない仕様になったりする可能性がある。
それでは AI の出したものに責任を持てないので、煮詰まったときはヒントをもらいながら、コードを自力で書くよう努めた。

今後は、AI が出したコードを読んで、正しいか判断できる側に立ちたい。
